# Cloud Services

Cloud-based systems revolve around the services provided by Azure. This course introduces the most important Azure services so students can better understand the core principles of cloud architecture and the relationships between different service areas.

## ☁️ Core Azure service areas

- **Compute:** Virtual machines, App Services, scalable computing resources
- **Storage:** Storage accounts, data services, databases, and backups
- **Networking:** Virtual Networks, load balancers, segmented network communication
- **Security & Identity:** Key management, access control, identity management

## 📌 Why cloud services matter

Cloud services enable:

- flexible capacity management
- faster development and operations cycles
- reliable, scalable, and secure infrastructure
- reduced operational overhead and greater automation

## 🧠 AZ-900 perspective

The AZ-900 curriculum introduces basic cloud concepts and Azure architecture with emphasis on cloud platforms, service models, and identity security.
