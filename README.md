# Felhőalapú számítástechnika kurzus

Üdvözöllek a **Felhőalapú számítástechnika** kurzus hivatalos repository gyűjteményében! Ez az organizáció a félév során elkészített feladatokat, adatmodelleket és lekérdezéseket tartalmazza, különös tekintettel az Azure erőforrásokra.

## Technológiai fókusz

A kurzus során az alábbi rendszerek mélyebb megismerésére koncentrálunk:
*   **Azure portal**: Felhőalapú stratégiai szemléletmód és technológiai alapok elsajátítása.
*   **Terraform**: : Az „Infrastruktúra mint kód” (IaC) elv alkalmazása és deklaratív erőforrás-kezelési készségek kialakítása.
  
## Repository-k felépítése

Az organizáció az alábbi bontásban tartalmazza a projekteket:

| Projekt | Leírás | Technológia |
| :--- | :--- | :--- |
| `terraform` | IaC AZ-900 témakörben | Terraform |
| `finals` | A féléves nagyprojekt dokumentációja és kódja | Terraform dokumentációval  |
